Logwarden

Every change in your server, on the record.

Add to Discord

Messages

Deleted and edited messages, including attachments and bulk deletes.

Members

Joins, leaves, kicks, bans, unbans, nickname and role changes.

Server

Channels, roles, emojis, stickers, invites and server settings.

Voice

Who joined, left or moved between voice channels.

Get started

1. Add Logwarden to your server.
2. Run /setchannel #logs. Every event is logged from then on.
3. Turn off anything you don't want with /config <event> false.

Both commands need the Manage Server permission.
